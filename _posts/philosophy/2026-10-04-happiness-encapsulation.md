행복하게 살기 위해선 무엇이 필요할까요? 돈? 건강? 사람마다 중히 여기는 가치가 다르니 필요한 것도 여러 가지겠지만, 저는 가장 중요한 건 '나답게 사는 것'이라고 생각합니다.

우리는 살아가면서 종종 남의 눈치를 보게 됩니다. 그러다 보면 내가 바라는 것보다 남의 기대를 채우기 위한 행동을 할 때가 있죠. 부모님이 기대하는 내 진로, 친구들이 기대하는 내 모습, 사회가 정의한 성공한 삶. 우리는 알게 모르게 이런 영향을 받으며 삶과 나를 만들어 갑니다.

이렇게 만들어진 내 모습이 만족스러운지는 사람마다 다르게 느끼겠지만, 확실한 건 타인의 기대로 만들어진 내 모습이 내 바람과 다를 때 행복하기는 어렵다는 겁니다.

나에 대한 타인의 기대라는 건 결국, 타인이 원하는 내 모습을 말합니다. 그렇기에 그 기대에 흔들릴 때 내 삶도 흔들릴 수밖에 없죠. 그래서 행복을 위해서는 두 가지가 먼저 필요합니다. 첫째, 나를 너무 드러내지 않아야 합니다. 둘째, 남의 말에 내 내면이 흔들리지 않아야 합니다.

프로그래밍에서는 이 두 가지를 정보의 은닉과 보호라고 부르고, 이를 지키는 것을 캡슐화라고 합니다. 코드로 한번 알아보겠습니다.

## 나를 다 드러내지 않아도 됩니다

내 내면, 바깥에서는 알 수 없는 나의 행복의 기준을 `private` 으로 정의하겠습니다.

```kotlin
class 사람 {
    // 바깥에서는 알 수 없는, 나만의 행복 기준
    private val 행복의_조건 = 행복의조건(
        필요한_돈 = 3_000_000,
        필요한_직업 = "좋아하는 일",
        필요한_명성 = "가까운 사람들의 인정",
    )
}

class 행복의조건(
    val 필요한_돈: Int,
    val 필요한_직업: String,
    val 필요한_명성: String,
) {
    fun 행복한가(): Boolean = TODO("이 기준을 채웠는지는 나만 판단한다")
}
```

`private` 으로 선언된 구성요소는 클래스 밖에서는 볼 수 없습니다. 무엇을 가지고 있는지 모르게 하는 것, 이걸 정보의 은닉이라고 합니다. 내 행복의 기준을 아무나 들여다볼 수 있다면, 사람들은 그걸 보고 저마다 한마디씩 얹고 싶어질 테고, 나 역시 그 말들을 신경 쓰지 않기가 어려울 겁니다.

## 받아들일지는 내가 정합니다

그렇다고 우리가 타인을 무조건 배제할 순 없습니다. 지나가는 말로, 무심코 지나친 쇼츠로, 지인의 SNS로 영향을 받을 것이고, 때로는 직접 상담을 받거나 조언을 들을 수도 있고, 실제로 도움이 되는 말을 들을 때도 있겠죠. 그러나 외부에서 어떤 자극이 들어왔을 때 그것을 받아들일지 말지를 판단하는 것은 오로지 자신이어야 합니다.

```kotlin
class 사람 {
    private val 행복의_조건 = 행복의조건(/* 필요한_돈, 필요한_직업, 필요한_명성 */)

    fun 조언_듣기(조언: String) {
        if (행복의_조건.필요한_말인가(조언)) {
            행복의_조건.귀담아듣기(조언)
        } else {
            // 흘려듣기
        }
    }
}
```

밖에서는 `행복의_조건` 을 직접 바꿀 수 없고, `조언_듣기` 라는 정해진 통로로만 말을 건넬 수 있습니다. 그 말을 내 기준에 더할지 흘려보낼지는 안에서 정합니다. 이렇게 내 상태가 정해진 통로로만, 내 판단을 거쳐서만 바뀌게 하는 것이 정보의 보호입니다.

타인이, 혹은 세상이 무엇이 행복의 조건이고 어느 정도가 행복의 기준점이라고 말한들, 내가 그렇게 느끼지 않고 나한테 맞지 않으면 그것을 위해 애쓰고 힘들어할 필요가 없습니다.

앞서 말했듯 행복의 기준은 내 안에 있어야 하니까요. 세상이 돈은 이만큼 벌어야, 직업은 이런 걸 해야, 이렇게 살아야 행복한 거라고 아무리 외친들, 나한테 와닿지 않는다면 흘릴 줄 알아야 합니다. 가장 중요한 것은 자기 자신입니다.

반대로 나 역시 남의 `private` 에 손대지 않아야 합니다. 내 기준은 지키면서 남에게는 "이렇게 살아야 행복하다"고 들이민다면, 그건 남의 필드를 밖에서 직접 바꾸려는 것과 같습니다. 내가 원하는 모습이 아니라고 상대를 억지로 바꾸려 하면 안 됩니다. 상대방을 있는 그대로 받아들이고, 혹 바라는 부분이 있다면 대화를 통해 합의점을 찾아가야 합니다. 상대가 열어 둔 통로로 말을 건네되, 받아들일지는 상대에게 맡기는 거죠.

나를 소중히 여기고 지키면서, 상대방의 자아도 지켜 주는 것. 그것이 상호 존중과 배려이고 서로가 행복하기 위한 첫걸음입니다.

## 마치며

캡슐화는 객체를 안전하게 쓰기 위한 최소한의 제약입니다. 우리도 마찬가지 아닐까요?

캡슐화가 폐쇄적으로 살라는 얘기는 아닙니다. `private` 으로 안을 감춘 객체도 바깥과 이야기하는 통로는 열어 두고, 그 통로로 메시지를 주고받으며 다른 객체와 소통합니다. 다만 받은 메시지로 자기 상태를 어떻게 바꿀지는 각자 안에서 정하죠. 잘 캡슐화된 객체들이 서로 엉키지 않고 협력하듯, 사람 사이도 서로의 내면을 지켜 줄 때 오히려 건강하게 가까워질 수 있습니다.

세상과 타인의 기대에 무분별하게 휘둘리기보다 스스로 기준을 정하고 캡슐화해서, 진짜 나의 행복을 좇는 인생을 살았으면 합니다.
